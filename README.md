# Portal Recall

A memory card game built as part of The Odin Project, featuring Rick and Morty characters.

[Live Demo](https://memory-card-eight-zeta.vercel.app/)

Built with React and Vite, with data fetched from the [Rick and Morty API](https://rickandmortyapi.com/).

## Run Locally

```bash
npm install
npm run dev
```
